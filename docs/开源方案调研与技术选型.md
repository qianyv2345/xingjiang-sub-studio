## 二、核心架构决策总结

1. **双对齐后端策略 (`FunASR fa-zh` + `Qwen3-ForcedAligner-0.6B` + `VAD 兜底`)**：
   - 用户常同时开启 DaVinci Resolve Studio 20 与剪映，RTX 4060 8GB 显存往往被占去 2~4GB。因此程序在“自动优选”模式下会实时检测可用显存：可用显存充足（≥2.2GB）且已缓存 `Qwen3-ForcedAligner-0.6B` 时优先用 Qwen3；显存受限或低配环境下自动切换 **159MB 的 `FunASR fa-zh` 或 CPU 回退**。
   - **绝不静默伪造对齐**：所有结果均经过 Silero VAD 重叠度与语音能量校验，静音区间或异常低置信度片段明确标注告警，供人工在波形轴复核。
2. **48kHz 智能人声音量均衡引擎**：
   - 自研融合了 `voxlevel` 的免切割平滑思路与 EBU R128 (`pyloudnorm`) 广播响度校准，并加入多尺度滑窗（句级 320ms + 音节级 80ms 微窗）、情绪动态保留系数、噪声门限（不盲目拉起静音底噪）、BGM 混合风险自动探测以及 GUI 局部人工增益节点叠加。
3. **动态规划 (DP) 独立单行/双行中文断句系统**：
   - 单行与双行分别执行独立合法性校验与语义评分，综合考虑标点等级、词性与词边界保护（绝不拆词/人名/成语/英文数字）、真实语音停顿、视觉显示宽度（区分中文全角与英文数字半角）、阅读速度 (CPS) 与显示时长，并通过原文字序列哈希/逐字一致性校验确保**零漏字、零错字**。
