# 星酱声幕 · AI 短剧智能音频与字幕修正助手

专为 **Windows 11 + DaVinci Resolve Studio 20 + 剪映** AI 短剧后期工作流设计的本地离线桌面工具（支持 NVIDIA CUDA GPU 加速与 CPU 自动回退）。

---

## 一、核心解决的问题

1. **直接导入视频与剪映 SRT**：支持 `.mp4`、`.mov`、`.mkv` 与 `.srt` 拖拽批量导入及多集自动配对，自动使用内置 FFmpeg/ffprobe 检测分辨率、帧率、时长、画面比例（横/竖屏）、多音轨选择及音画基准偏移，无需用户手动导出 WAV。
2. **自定义字幕排版模板（支持 1 行 / 2 行与滑块自由调节）**：
   - **竖屏 9:16 预设**：默认每行最多 9 字、1 行；
   - **横屏 16:9 预设**：默认每行最多 20 字、1 行；
   - **每行最多字数**：5～40 字平滑拖动滑块 + 精确数值输入 + 实时预览；
   - **每条字幕最大行数**：`1 行` / `2 行` 独立分段切换，具备互不干扰的两套排版逻辑；
   - 支持智能语义断句、自动去标点（保留小数点 `3.14`、千分位 `1,000`、英文连接符 `AI-2026`）、最短/最长显示时长、最大阅读速度、最小字幕间隔、首尾偏移、过短合并、过长拆分、自定义模板增删改复制与项目级独立记忆。
3. **中文语音强制对齐与动态规划断句**：
   - 结合 `Silero VAD`、中文分词/词性标注、人名/成语/固定搭配保护、真实音频停顿与字词级时间戳，使用动态规划（DP）求全局最优断句；
   - 支持 **FunASR (`fa-zh`, ~160MB 轻量高速)** 与 **Qwen3-ForcedAligner-0.6B (~1.84GB 高精度)** 双引擎，并内置安全一致性校验（绝不擅自增删改台词）与低置信度/静音区异常标记（绝不平均分配伪造对齐）。
4. **智能人声音量均衡（48kHz 工作室级）**：
   - 解决不同片段音量不一致、前小后大/前大后小、一句话内突然变小、一两个字突兀大小声、不同人物音量差异及整集响度不均；
   - 免切割平滑动态增益曲线 + 情绪保留（保留喊叫与耳语对比） + 静音底噪防泵音门限 + 5ms 前瞻真峰值限制器（防止削波）；
   - 提供 **轻度 / 标准 / 强力** 三档及高级参数，支持 **A/B 实时切换对比试听** 与 **波形上局部人工增益点调节（支持撤销/重做）**。
5. **DaVinci Resolve Studio 20 无缝导出**：
   - 输出 `第XX集_修正音频.wav`（48kHz 24-bit/16-bit 严格与视频时间零点同步）、`第XX集_修正字幕.srt`（UTF-8 无 BOM + Unix LF 换行 + 严格无重叠时间码）、`第XX集_修正报告.json` 及可选替换音轨的无损视频流 `.mp4`。

## 二、快速使用指南（剪映 → 本程序 → DaVinci Resolve Studio 20）

### 第一步：模型准备（首次使用，之后可完全离线）
1. 启动程序（桌面安装包 `XingJiangSubStudio.exe` 或源码运行 `python -m drama_studio.app`）。
2. 点击顶部工具栏 **「模型下载与缓存」**：
   - 若显存紧张或希望极速处理，推荐下载 **FunASR `fa-zh` (~160 MB)**；
   - 若配备 RTX 4060 8GB 且追求中英混排/短句极限对齐精度，可下载 **Qwen3-ForcedAligner-0.6B (~1.84 GB)**；
   - 若希望自动校正达芬奇大跨度二次剪辑导致的时间轴偏移，可再下载 **FunASR `paraformer-zh` (~850 MB)**。

### 第二步：拖入素材与自动配对
- 将粗剪导出的单集或多集 `.mp4 / .mov / .mkv` 与剪映导出的 `.srt` 一起拖入左侧窗口（或拖入整文件夹）。
- 若视频包含多音轨（例如轨道 1 为伴奏、轨道 2 为人声对白），请在左侧 **「提取音轨」** 下拉框选定对白音轨。

### 第三步：设置字幕排版模板与音频参数
- 右侧面板自动匹配 9:16 竖屏或 16:9 横屏预设，可随时拖动 **「每行最多字数 (5~40)」** 滑块、切换 **「1 行 / 2 行」**，下方会即时渲染排版预览效果。
- 中上方音频面板选择 **轻度 / 标准 / 强力** 均衡强度。

### 第四步：一键智能修正、复核与局部微调
- 点击 **「一键智能修正 (当前集)」** 或 **「批量处理全部集」**。
- 处理完成后：
  - 点击 **「A · 原片人声」 / 「B · 智能均衡后」** 实时对比试听；
  - 在中间波形图中 **左键点击可添加绿色的局部人工音量调节节点并上下拖动**（右键删除），随后点击 **「重新应用均衡曲线」**；
  - 在时间轴拖拽字幕左右边缘微调起止点，或在字幕表格中直接修改断行、合并/拆分字幕（支持 `Ctrl+Z` 撤销 / `Ctrl+Y` 重做）；
  - 查看下方 **「异常区间检查」**，点击任意条目直接跳到对应时间点核对。

### 第五步：导回 DaVinci Resolve Studio 20
1. 点击 **「重新导出当前集」** 或直接进入输出目录（默认位于原视频同级 `智能修正输出/` 文件夹，**绝不覆盖原始视频与原 SRT**）。
2. 在 DaVinci Resolve Studio 20 的媒体池导入 `第XX集_修正音频.wav` 与 `第XX集_修正字幕.srt`：
   - 确保时间线帧率与原视频一致；
   - 将 `修正音频.wav` 放在新音轨 `00:00:00:00`（原视频有起始音画偏移时程序已自动补偿对齐），静音原视频音轨；
   - 将 `修正字幕.srt` 拖入字幕轨（已自动处理 UTF-8 无 BOM 与 LF 换行，避免达芬奇吞字或行合并错乱）。

## 三、开发运行与源码打包说明

### 从源码运行
```powershell
.venv\Scripts\python.exe -m drama_studio.app
```

> 若从源码运行且尚未打包，请将 LGPL FFmpeg/ffprobe 放入 `vendor/ffmpeg/bin/`（包含 `ffmpeg.exe` 与 `ffprobe.exe`），或直接使用 GitHub Releases 中的 Windows 独立发行包（已内置）。

### 运行全部自动化测试
```powershell
.venv\Scripts\pytest.exe -v
```

### 打包为 Windows 独立可执行程序
```powershell
.venv\Scripts\python.exe scripts\build_exe.py
```
产物位于 `dist\XingJiangSubStudio\XingJiangSubStudio.exe`（内置 LGPL FFmpeg/ffprobe，用户端无需另行配置 Python 或 FFmpeg 环境变量）。

## 四、已知限制与注意事项

1. **已混音 BGM / 音效分离限制**：若粗剪视频中人声已与大音量背景音乐或爆炸音效混为同一音轨，任何无源信息分离均无法做到 100% 无损人声分离；程序会自动探测较高非语音电平并给出风险提示，建议此类素材优先使用「轻度」或「标准」均衡模式并结合 A/B 试听确认。
2. **达芬奇与本地模型共用显存**：若与 DaVinci Resolve Studio 20 同时开启且显卡为 6GB~8GB 显存，达芬奇可能会占用 2~4GB 显存；当可用显存低于 ~2.2GB 时，`Qwen3-ForcedAligner-0.6B` 会自动切换到更稳妥的 CPU 或由「自动优选」调度至轻量 `FunASR fa-zh`。
3. **绝对原话不改写原则**：若剪映原始 SRT 本身识别错了同音字（例如把人名“顾寒川”误识为“顾汉川”），本工具的强制对齐与智能断句**不会擅自修改用户原文**，建议在剪映或本软件内先核对文字再对齐。
4. **未下载任何对齐模型时**：程序仍可通过内置 `Silero VAD` 执行基础语音区间分布估算，但会将置信度标记为偏低并提示下载 `fa-zh` 或 `Qwen3` 模型以获得字级毫秒对齐精度。
